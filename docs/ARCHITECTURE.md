# 架构说明

```text
┌─────────────────── 浏览器 ───────────────────┐
│  React 控制台（Vite）                          │
│  工作台 · 捕获 · 载荷 · 告警 · …                 │
└─────────────────────┬─────────────────────────┘
                      │ HTTP /api/v1
┌─────────────────────▼─────────────────────────┐
│  PayloadX API（FastAPI）                       │
│  路由 → 服务 → SQLAlchemy 模型                  │
└───────────┬─────────────────────┬─────────────┘
            │                     │
   ┌────────▼────────┐   ┌────────▼────────┐
   │ SQLite / MySQL  │   │ uploads/*.pcap  │
   └─────────────────┘   └─────────────────┘

解析流水线（后台线程）
  PCAP 文件
    → 帧解码（以太网 / IPv4 / TCP|UDP）
    → 五元组流聚合
    → 有界流缓冲
    → HTTP / DNS / TLS 提取
    → 规则告警（敏感字段、大流量）
    → 落库：会话 + 载荷 + 告警
```

## 模块对照

| 路径 | 职责 |
|------|------|
| `backend/app/api/routes.py` | REST 接口 |
| `backend/app/services/pcap_parser.py` | 纯 Python PCAP 与提取 |
| `backend/app/services/task_runner.py` | 任务调度 |
| `backend/app/models/entities.py` | 持久化模型 |
| `src/pages/*` | 产品页面 |
| `src/lib/api.ts` | 前端 API 客户端 |

## 设计原则

1. **本地优先**：默认 SQLite，安装成本低  
2. **解析隔离**：核心路径不依赖重型原生库  
3. **台账模型**：任务 / 会话 / 载荷 / 告警  
4. **加密边界诚实**：不伪造 HTTPS 解密能力
