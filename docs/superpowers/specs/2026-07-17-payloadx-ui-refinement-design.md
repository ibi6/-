# PayloadX 第二轮 UI 精修设计

**日期：** 2026-07-17

## 目标

在不改变现有业务流程和浅色工作台方向的前提下，消除通用后台模板感，让应用界面与 README 已建立的“深海网络取证工作台”品牌一致，并提升移动端的信息密度。

## 当前证据

基于运行中的真实后端数据，在 1440 × 900 与 375 × 812 两种视口完成了首页、流量捕获、载荷列表、载荷详情和系统配置页审计。

主要问题：

- 默认科技蓝与仓库品牌青绿不一致。
- 侧栏使用通用二进制图标和“载荷提取系统”名称，PayloadX 品牌识别弱。
- 页头存在无实际行为的未读通知和虚拟 `admin` 身份表达。
- 白色卡片的圆角、阴影和层级过于一致，缺少主次。
- 首页移动端五张指标卡单列堆叠，关键分析内容被推到首屏之外。
- 载荷筛选器在 375px 下换成多行，占用过多垂直空间。
- 捕获页只有一个任务时右侧卡片信息偏薄，留白缺少意义。

## 设计选择

采用“品牌一致性 + 信息密度优化”，不做全站深色化，也不重构业务页面。

### 品牌系统

- 新用户默认强调色改为青绿品牌色；已保存主题的用户保持原选择。
- 将青色主题命名为“深海青”，描述为“PayloadX 品牌色”。
- 应用首帧 CSS 变量与默认主题保持一致，避免蓝色闪烁。
- 新增可复用的 PayloadX 品牌标识，使用扫描线图形而不是二进制占位图标。

### 应用壳层

- 侧栏主标题使用 `PayloadX`，副标题使用 `NETWORK FORENSICS`。
- 导航分为“调查工作区”和“系统与支持”，分组只影响视觉，不改变路由。
- 活跃导航使用青绿细轨、深色半透明底和更清晰的图标状态。
- 页头保留页面上下文、主题切换和上传入口；移除无行为通知。
- 将虚拟 `admin` 改为诚实的“本地模式”状态。
- 主内容设置合理最大宽度，避免超宽屏无限拉伸。

### 首页

- 页面标题改为“调查工作台”，避免未实现认证时称呼管理员。
- 手机端指标区使用“一张主指标 + 四张双列小指标”，减少首屏滚动。
- 指标卡统一使用更紧凑的数字、图标和间距，主卡保留深色差异层级。

### 流量捕获

- 上传区使用更轻的品牌渐变和响应式高度。
- 增加“本地处理 / 流式上传 / 文件校验”能力标签，内容均对应现有实现。
- 最近任务增加包、会话、载荷三项统计，低数据量时仍能形成有效信息层级。

### 载荷列表

- 搜索、类型过滤和视图切换明确分层。
- 手机端类型过滤改为容器内横向滚动，不产生页面横向溢出。
- 表格/卡片切换使用图标与文字组合，保留完整可访问名称。

## 组件边界

- `BrandMark`：只负责品牌图形，可由桌面侧栏和移动抽屉复用。
- `SidebarNavigation`：只负责导航分组和活动态，可接受关闭移动菜单的回调。
- `Header`：只负责全局上下文和全局操作，不读取业务页面数据。
- 页面继续使用现有 `Card`、`PageHeader`、`Button` 和 API 模型。

## 响应式与可访问性

- 375px 页面 `scrollWidth` 必须等于视口宽度。
- 交互目标最小高度保持 44px。
- 导航、筛选和视图切换继续暴露 `aria-label`、`aria-pressed` 或语义角色。
- 横向筛选容器可触摸滚动，但隐藏装饰性滚动条。
- 保留 `prefers-reduced-motion` 支持。

## 验收标准

- 新会话默认使用深海青，主题选择和持久化仍工作。
- 桌面与移动导航覆盖全部十个现有模块。
- 页头不再显示无行为通知或虚拟管理员身份。
- 首页在 375px 首屏至少能看到主指标和两张次级指标。
- 捕获任务能显示包、会话和载荷计数。
- 载荷筛选在 375px 不换成三行标签，页面无横向溢出。
- 前端测试、Lint、生产构建、后端测试与 Git 差异检查全部通过。
- 1440 × 900 和 375 × 812 的关键页面实际截图无裁切、遮挡和异常留白。
