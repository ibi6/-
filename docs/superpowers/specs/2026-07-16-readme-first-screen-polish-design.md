# PayloadX README 首屏视觉优化设计

**日期：** 2026-07-16

## 目标

把仓库首页首屏从“横幅 + 重复标题 + 多色徽章”升级为统一、克制、有网络取证产品辨识度的展示，同时保持 GitHub 明暗主题、桌面端和窄屏下都能稳定阅读。

## 可控范围

- 可调整：`README.md` 中的横幅、说明、徽章和页内导航，以及 `docs/assets/banner.svg`。
- 不可调整：GitHub 自动生成的“自述文件 / 行为守则 / 贡献 / 许可证 / 安全”导航及右侧平台按钮。
- 不引入 JavaScript、外部字体或新的运行时依赖。

## 视觉方向

- **基调：** 深海蓝黑背景，青绿色为唯一主强调色，少量冰蓝用于数据层级。
- **构图：** 左侧为品牌、定位和流程；右侧为“分析流水线”产品面板，形成非对称视觉重心。
- **质感：** 低对比网格、柔和径向光晕、细边框和层级化面板，不使用大面积霓虹或装饰圆形堆叠。
- **排版：** `PayloadX` 是唯一一级标题；英文眉题与等宽数据标签增强工具属性；中文说明保持清晰。
- **徽章：** 从七枚多色徽章压缩为五枚统一暗色胶囊，仅用青绿区分关键状态。

## README 首屏结构

1. 全宽品牌横幅。
2. 一行统一视觉的核心能力徽章。
3. 两行以内的产品价值说明，不重复产品名。
4. 简洁页内导航，使用中点分隔。

## 验收标准

- 横幅 SVG 能被浏览器独立加载，无缺字、裁切或元素越界。
- 1280px 原始画布层级清晰，缩放到约 640px 宽仍能识别品牌与主要信息。
- README 首屏不再出现横幅内外重复标题。
- 所有徽章色彩和形状一致，链接仍可用。
- Markdown、SVG XML、项目测试、构建和 Git 差异检查全部通过。
