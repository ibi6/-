## 本地运行

```bash
# 后端
cd payloadx/backend
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
uvicorn app.main:app --reload --host 127.0.0.1 --port 8000

# 前端
cd payloadx
npm install
npm run dev
```

前端默认请求 `http://127.0.0.1:8000/api/v1`。
